# Accessibility Ninja review instructions

- Preserve keyboard access, visible focus, semantic headings, and explicit labels in the UI.
- Keep the status and error feedback available to screen readers with live regions.
- Never claim a deck is accessible or WCAG-conformant from automated checks alone.
- Never treat generated or non-empty alt text as speaker-approved meaning.
- Keep slide numbers, original object sequence, findings, and approval state traceable.
- Do not silently rewrite or discard speaker notes, slide content, or private material.
- Validate file size and uploaded PPTX structure before extracting it.
- Search must retrieve indexed slide text and approved explanations; do not add a chatbot/RAG layer without a concrete user task.
